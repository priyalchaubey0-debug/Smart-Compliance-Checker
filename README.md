
# Smart Compliance Checker

## Project Overview
A Python-based project that extracts text from PDF documents and checks it against predefined compliance requirements.

## Project Files

### reader.py
- Reads PDF files using PyPDF2.
- Extracts text from PDF pages.
- Displays the total number of pages and extracted content.
- Handles basic errors.

### compliance_checker.py
- Checks extracted PDF text against 11 predefined requirements.
- Displays PASS or FAIL for each requirement.
- Provides a summary of the results.

### sample.pdf
- Sample PDF used as input.
- Contains the compliance requirements.

### extracted_text.txt
- Stores the text extracted from the sample PDF.
- Generated by the PDF reader.

### .gitattributes
- Contains Git configuration for repository files.

## Technologies Used
- Python
- PyPDF2
- Git
- GitHub

## Project Purpose
To simplify PDF text extraction and basic compliance requirement checking.

## Note
This project currently uses exact text matching. A PASS result does not guarantee complete real-world compliance.
